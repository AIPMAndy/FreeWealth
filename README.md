# FreeWealth · 科学驱动的个人财富自由

> 用科学方法发现、验证并扩大个人创造经济价值的能力。

FreeWealth 是一个研究与实验工具项目，不是投资荐股、收益保证或物理学直接预测财富的系统。我们把成熟数学方法、跨领域模型和科学启发明确分级，以真实付费、贡献利润、投入时间和风险来评估商业假设。

## 立即使用

1. 打开 `index.html`，离线使用商业漏斗、贡献利润和创始人工时计算器。网站部署入口：[GitHub Pages](https://aipmandy.github.io/FreeWealth/)（须启用 Pages）。
2. 阅读 [科学模型地图](docs/science-map.md)，选择一个模型。
3. 阅读 [研究协议](docs/research-protocol.md)，预先定义假设、对照、成功门槛和止损条件。
4. 使用 [实验台账](experiments/registry.csv) 记录实验和真实结果，示例行为空白结果，不得当成实测数据。
5. 使用 [30 天行动方案](docs/30-day-playbook.md) 完成首轮实验。

## 科学标准

- A：可直接用数学或统计方法建模；参数、目标与假设仍需验证。
- B：跨学科机制，可形成有证伪条件的商业假设；不保证适用。
- C：启发式类比，不可用物理公式计算商业收益。
- 研究必须同时记录正面、负面、零结果及不确定性。
- 营收不是利润，利润不是现金流，粉丝、曝光、Token 和代码提交不是收入。
- 不上传真实客户个人数据、商业机密、账户数据；公开案例须匿名并获授权。

## 当前范围

v0.1：20 个候选模型、研究规范、30 天行动方案、实验台账、离线情景计算器、计算单元测试。没有真实业务数据，没有实证赚钱结论，没有自动交易、自动发布或联网抓取。

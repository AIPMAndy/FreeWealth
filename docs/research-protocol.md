# 研究与实验协议

每次实验先登记：科学来源、迁移等级、可证伪假设、目标人群、实验组和对照组、随机化或匹配办法、主指标、观察窗口、预算上限、风险、停止与扩大标准。小样本只提供探索性证据。不能从浏览量推断营收因果。

## 商业模型定义

- 有效曝光：去重口径固定的目标人群触达数；合格线索：满足预先定义的意向和适配条件的潜在买家。
- 预期付费订单 = 曝光 × 合格线索率 × 付费转化率。
- 净营收 = 可履约订单 × 客单价 × (1 − 退款比例)；此处客单价为同一产品平均价，不包含代收税费。
- 贡献利润 = 净营收 − 订单变动成本 − 归因获客费用。
- 经营结余（简化）= 贡献利润 − 固定费用；未计所得税、融资费用、折旧及现金到账时差。
- 总人工工时 = 固定运营工时 + 可履约订单 × 单订单人工工时；每人工小时贡献 = 贡献利润 / 总人工工时。
- 现金流必须另做收付款台账，利润不能替代现金流。容量不足时不计算超出产能的订单为收入。

## 结果判断

1. 质量与履约为硬约束；不为了优化单一指标损害用户利益。
2. 在预算上限内取得对照数据。样本有限时报告区间或仅描述观察差异。
3. 正面结果独立复验；负面结果记录原因；零结果如实保留。
4. 只有在边际收益与产能、退款、获客成本同时可接受时，逐步扩大。
5. 严禁伪造用户案例、收益承诺、侵权获客、未授权数据处理与自动交易。

# 科学模型地图

等级描述见 README。A 不意味着存在已被证明的普适赚钱公式；C 不得包装成自然定律驱动的商业预测。

| 模型 | 级别 | 商业假设 | 首个可观测指标 |
|---|---|---|---|
| 相对论 / 参考系 | C | 同一技能在不同客户场景的付费价值不同 | 每个合格线索的贡献利润 |
| 热力学 / 熵 | C | 减少重复维护能释放可交付时间 | 每周维护工时、故障率 |
| 能量守恒 | C | 资源投入产出应独立核算 | 每创始人工时贡献利润 |
| 最小作用量 | C | 比较可行路径的总成本；物理作用量不是商业成本 | 获得相同结果的总成本 |
| 量子隧穿 | C | 寻找合法替代渠道；不存在商业隧穿概率公式 | 合格线索获取成本 |
| 相变 | B | 网络或产能可能出现非线性增长 | 阈值前后转化曲线，控制混杂 |
| 统计力学 | B | 聚合分布可帮助识别波动；不假设独立同分布 | 试验结果分布与置信区间 |
| 混沌理论 | B | 对初始条件的敏感性提示压力测试 | 极端情景损失、敏感性 |
| 复杂系统 | B | 模块化与反馈可能降低协作摩擦 | 端到端周期、返工率 |
| 信息论 | A | 降低特定不确定性；语义价值与 Shannon 信息量不是同一概念 | 决策前后预测误差 |
| 网络科学 | A | 比较传播与转介绍网络的连接结构 | 有效转介绍率、传播深度 |
| 幂律与重尾 | A | 测试利润贡献是否高度集中；不要预设幂律成立 | 前 10% 项目的利润占比 |
| 控制论 | A | 按延迟和反馈信号纠偏 | 实际与目标差距、纠偏时间 |
| 进化与选择 | B | 小批试验，保留有效策略 | 实验成本、复验成功率 |
| 博弈论 | A | 改变激励和机制可能提升双方收益 | 留存、成交、履约、净收益 |
| 贝叶斯统计 | A | 根据观测更新假设与概率 | 预测校准、后验区间 |
| 运筹学 | A | 在预算、时间、产能约束下求更优分配 | 贡献利润、约束利用率 |
| 多臂老虎机 / 强化学习 | A | 在适当假设下平衡探索与利用 | 累计收益、探索成本 |
| 因果推断 | A | 使用随机或合理准实验识别增量 | 处理组与对照组差异及不确定性 |
| 人工智能与智能体 | B | 自动化在特定任务中降低成本或提高质量 | 人工总时长、质量、净成本 |
